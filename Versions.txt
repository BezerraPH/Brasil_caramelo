  1. VISÃO GERAL
================================================================================

Nome: Brasil Caramelo
Tipo: Rede social brasileira com múltiplos "modos" de apresentação
Estado: MVP em desenvolvimento ativo (Fase 1 + reputação avançada)

Conceito:
  Uma rede social que pode se apresentar de várias formas — começando pelo
  modo Feed (estilo comunidade / Orkut). No futuro: modo Insta (grade de fotos),
  Reels (vídeos curtos), jogo do cachorro, chats, grupos, chamadas e reuniões.

================================================================================
  2. STACK TÉCNICA
================================================================================

Frontend / Backend:
  - Next.js 16 (App Router)
  - React 19
  - TypeScript
  - Tailwind CSS 4

Banco de dados:
  - PostgreSQL 16
  - Prisma 7 (client em src/generated/prisma, adapter @prisma/adapter-pg)

Autenticação:
  - Sessão por cookie httpOnly (bc_session)
  - Senhas com bcrypt
  - COOKIE_SECURE=false em HTTP local (docker-compose)

Deploy:
  - Docker + Docker Compose (app + postgres)
  - Gitea self-hosted para versionamento (pasta ~/gitea no servidor)

Scripts npm:
  - npm run dev          — desenvolvimento local
  - npm run build        — prisma generate + next build
  - npm run start        — produção
  - npm run db:migrate   — migrações em dev
  - npm run db:deploy    — migrações em produção
