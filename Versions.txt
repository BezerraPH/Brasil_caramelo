  1. VISÃO GERAL
================================================================================

Nome: Brasil Caramelo
Tipo: Rede social brasileira com múltiplos "modos" de apresentação
Estado: MVP em desenvolvimento ativo (Fase 1 + reputação avançada)

Conceito:
  Uma rede social que pode se apresentar de várias formas — começando pelo
  modo Feed (estilo comunidade / Orkut). No futuro: modo Insta (grade de fotos),
  Reels (vídeos curtos), jogo do cachorro, chats, grupos, chamadas e reuniões.

Identidade visual (cores):
  - Branco (#FFFFFF)
  - Azul (#1B6CA8)
  - Verde (#2D8B57)
  - Marrom (#8B5E3C)
  - Caramelo (#C68642) — destaque

Servidor de referência do usuário:
  - Ubuntu 26.04 LTS (ntek-servidor)
  - IP LAN: 192.168.1.4
  - Tailscale: 100.94.55.27
  - App: http://192.168.1.4:3000
  - Gitea (Git): http://192.168.1.4:3001 (SSH Git na porta 2222)

================================================================================
  2. STACK TÉCNICA
================================================================================

Frontend / Backend:
  - Next.js 16 (App Router)
  - React 19
  - TypeScript
  - Tailwind CSS 4

Banco de dados:
  - PostgreSQL 16
  - Prisma 7 (client em src/generated/prisma, adapter @prisma/adapter-pg)

Autenticação:
  - Sessão por cookie httpOnly (bc_session)
  - Senhas com bcrypt
  - COOKIE_SECURE=false em HTTP local (docker-compose)

Deploy:
  - Docker + Docker Compose (app + postgres)
  - Gitea self-hosted para versionamento (pasta ~/gitea no servidor)

Scripts npm:
  - npm run dev          — desenvolvimento local
  - npm run build        — prisma generate + next build
  - npm run start        — produção
  - npm run db:migrate   — migrações em dev
  - npm run db:deploy    — migrações em produção

  GET|POST /api/uploadthing
  POST /api/pusher/auth

  8. VARIÁVEIS DE AMBIENTE
================================================================================

DATABASE_URL     — PostgreSQL (obrigatório em runtime)
COOKIE_SECURE    — "true" com HTTPS; "false" em HTTP local (docker-compose)
NODE_ENV         — production no Docker
UPLOADTHING_TOKEN — token do dashboard Uploadthing (upload avatar/fotos)
NEXT_PUBLIC_PUSHER_KEY / NEXT_PUBLIC_PUSHER_CLUSTER — cliente Pusher
PUSHER_APP_ID / PUSHER_KEY / PUSHER_SECRET — servidor Pusher (mesmo KEY do público)
